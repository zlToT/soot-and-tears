# SOOT & TEARS · 煤与泪

一个像素风、房间制的地牢射击小游戏。你扮演煤灰世界的「阿灰」，从 B1 一路往下打，直到 B15 的无名。

> 机制致敬《以撒的结合》，角色、怪物、Boss、道具、音效全部原创；非商业同人项目，供自用与个人网站展示。

---

## 一局是怎么玩的

- 一局 = 15 层（B1–B15）。每层是一张 **9×8 网格生成的小地牢**，实际 5–20 间房，四向门连接。
- 每层固定有 **1 个 Boss 房 + 1 个宝物房 + 若干普通房**；第 2 层起多一个商店。
- 清光房间所有可行动的怪才会开门；泥娃娃化泥期间不锁门。进 Boss 房击败 Boss，房间中央出现**活板门**，踩下去进入下一层。
- 第 15 层击败「无名」后通关，显示本局结算（击杀 / 道具 / 存活时间 / 到达层数 / 探索房间 / 击败 BOSS）。
- 血量、金币、道具、炸弹、钥匙跨层保留；死亡即本局结束，从 B1 重开。
- **存档**：3 个槽位，每次下到新一层自动存检查点；打开页面先进主界面，「继续游戏」读最深存档或直接点槽位，`C` 继续最新、`1`–`3` 选指定槽（死亡 / 通关只清当前槽）。存档带校验和，旧单槽存档会自动迁移。

## 操作


| 动作                  | 键盘                               | 手机（横屏）       |
| --------------------- | ---------------------------------- | ------------------ |

## 生存与战斗

- 初始 4 颗心（8 个半心），受伤后 1.25 秒无敌。
- 半心 +1、红心 +2；道具可以提供每房护盾、减伤、复活、环绕炮台等。
- 进普通房有 **0.7 秒出场动画**：敌人套白圈并缓缓放大，期间不行动、不受伤；Boss 用更大的圈和 0.9 秒无敌。
- 命中 / 击杀 / 受伤 / Boss 死亡都有 **hit-stop** 和粒子；**震屏只给击杀、Boss 死亡、受伤和炸弹**，普通射击不震。
- 泪默认带一点自动修正：前方 ±15° 内最近的敌人或可破坏石头会把弹道轻轻带过去；「嗅泪」则是全向强追踪。
- 玩家、敌人、Boss、石头和宝箱按脚底位置分前后层级，站到石头后面会被挡住；静止时有轻微呼吸 idle。
- 怪物和 Boss 用 3 帧循环做呼吸/振翅/滚动，玩家走动扬尘、开枪有枪口闪光，房间里飘着灰烬；商店货架直接显示道具图标。
- B1–B15 每层一套地板/墙/火把/灰烬配色；战斗房加入八角、墙体立柱、壁龛、十字隔断等非矩形布局。
- 数值重新调平：小怪/Boss 血量增长放缓，铁面卫正面减伤 65%，全道具下 B15 小怪几发泪即可清掉。
- GM 面板新增一键全加；已拥有的道具显示 ✓，再点一次取消拥有；另有无敌开关和“跳到 Boss”。
- 敌人死亡会白闪、炸开血环、留下地面血迹。

## 房间与地貌

- 13 种房间布局：空房、四角、立柱、菱形、坑洞群、断行、尖刺环、镜像散布、尖刺走廊、双坑、竞技场、对角碎石、十字立柱。
- 石头：挡人挡泪，3 滴泪可打碎，可能掉金币。
- 坑洞：挡人不挡泪，飞行敌人可越过。
- 尖刺：不挡路，踩上扣半心。

## 敌人与 Boss

- Boss 不再只丢子弹：深井之主会踩击/横扫，白袍人会十字激光/冲刺，无名会六向激光/踩击/召唤；装甲蛆的尾节会发光提示。
- 14 种普通敌人：煤渣虫、灯蛾、吐酸菇、铁皮鼠、跳跳痂、爆囊蛾、弹簧蟾、吊口、泥娃娃、铁面卫、血线虫、影蛾（瞬移）、裂蛆（死亡分裂）、刺球（滚弹）。
- 15 档 Boss：锅炉奶奶、蝇王、排水管虫、贪吃囊、肉瘤墙、锅炉爷爷、心脏吊灯、阁楼腿、装甲蛆、静默者、深井之主、白袍人、无名（前几层重复，详见 `docs/MECHANICS.md`）。
- Boss 半血进入二阶段；分节 Boss（排水管虫、贪吃囊、装甲蛆）有全身判定与尾节弱点。

## 道具（65 件）

- 一局内不重复，从宝物房、Boss 奖励、宝箱、商店、杂兵掉落中获得，效果叠加。
- 攻击类 27 件：多重射击、穿透、追踪、反弹、回旋、分裂、爆炸、中毒、减速、幽灵泪、暴击、距离/首发增伤、伤害光环、蓄力激光……
- 生存类 8 件：护盾、减伤、复活、炮台、磁吸、反刺、清房回血、击杀回血。
- 属性类 22 件：伤害 / 射速 / 移速 / 弹速 / 射程 / 生命上限 / 幸运。
- 外观类 8 件：体型、骨翼、浮空、光环、暗环、足印、环绕、泡膜（只改表现，不改碰撞）。

## 经济

- 金币来自清房、杀怪、碎石、宝箱、Boss；HUD 底部用图标 + 数字显示击杀 / 金币 / 炸弹 / 钥匙。
- 商店三个货架，商品上方标出名称与说明，价格随层数上涨，**踩上货架即购买**；偶尔卖红心容器（生命上限 +1 并回满）。
- 宝箱：木箱免费；金箱上锁，需要 1 把钥匙；开箱有盖子弹开的动画。
- 炸弹：范围伤害、炸碎石头、也会伤到自己；初始 2 颗。

## 界面

- 主界面：游戏名、简介、操作说明、`开始探索`、`继续游戏` 和三个存档槽；进入游戏 / 返回主界面都有淡出淡入。
- 640×360 逻辑 + 2× 渲染缓冲，文字按 2× 光栅化；画布只做整数倍缩放并居中，字号小而清晰。
- 顶部显示章节与楼层（如 `灰烬地下室 · B1`）；左上角一行是金币 / 击杀 / 炸弹 / 钥匙图标 + 数字，血条在下一行、再下面是本局时间；左侧中间竖排速度 / 射速 / 伤害 / 射程 / 弹速 / 幸运；右上小地图带金边面板，按本层实际范围裁剪，显示房间类型与门连线；左下排列已持有道具的像素图标，超出向上堆叠，鼠标悬停可看名称与说明。
- 进门 / 下层是滑屏过渡：旧画面滑出、新房间从对应方向滑入，HUD 固定在屏幕上。
- 暂停面板有音量滑条、静音、震屏、命中停顿、`继续游戏` 和 `返回主界面`（当前存档保留）。
- 右下角 GM 调试面板：B1–B15 任意跳层、65 件道具点击即加，打开时冻结游戏。
- 死亡 / 通关结算：`YOU DIED` / `ESCAPED`，六项统计（击杀 / 道具 / 存活时间 / 到达层数 / 探索房间 / 击败 BOSS）、道具列表，以及 `再来一次` / `返回主界面` 按钮。

## 表现

- 14 个原创合成音效 + 16 秒循环 BGM，全部由 `tools/gen_sfx.py` 用标准库合成。
- 640×360 逻辑分辨率、2 倍整数缩放、16 色调色板、1px 深描边。

## 技术栈与运行

```bash
pnpm install
pnpm dev        # http://localhost:5180/
pnpm build      # 产物在 dist/
pnpm typecheck
python tools/gen_sfx.py    # 重新生成音效（纯标准库）
```

- Phaser 4 + TypeScript + Vite，无额外运行时依赖。
- `tools/` 里是生成脚本与 CDP 冒烟测试，不参与打包。
- `docs/PROJECT.md` 是项目状态，`docs/MECHANICS.md` 是机制规格，`docs/shots/` 是截图。
