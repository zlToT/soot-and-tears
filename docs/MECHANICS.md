# SOOT & TEARS · 玩法机制规格

> 目标：复刻《以撒的结合》的核心机制，角色、怪物、Boss、道具全部原创命名与形象。
> 技术：Phaser 4 + TypeScript + Vite，逻辑分辨率 640×360，2 倍整数放大。
> 本文是开发规格，不是最终数值平衡表；标「已实现」的条目已经在 `src/` 里跑通。

---

## 1. 画面与输入

| 项 | 规格 |
|---|---|
| 逻辑分辨率 | 640×360（16:9），`Scale.FIT` + `CENTER_BOTH` |
| 像素 | `pixelArt: true`、`roundPixels: true`、`image-rendering: pixelated` |
| 房间 | 624×336，墙厚 24，内区 576×288 = 18×9 个 32px 格 |
| 键盘 | WASD 移动，方向键施法（四向） |
| 手机 | 横屏；左侧 360° 摇杆，右侧四向施法键；竖屏只显示旋转提示 |
| 多点触控 | 移动与施法可同时按，施法键支持滑动换向 |

输入统一为 `{ mx, my, shootDir }`，核心逻辑不判断设备。

## 2. 玩家

生命以**半心**为单位，起始 8 半心（4 颗心）。

| 属性 | 基准值 | 说明 |
|---|---|---|
| maxHp | 8 | 半心 |
| damage | 3.5 | 每颗泪 |
| fireRate | 2.8/s | 射击间隔 = 1 / fireRate |
| speed | 140 px/s | 640×360 下的缩放值 |
| range | 315 px | 泪的飞行距离 |
| shotSpeed | 345 px/s | 泪的速度 |
| luck | 0 | 影响掉落与暴击类道具 |

- 泪默认带轻微自动修正：前方 ±15° 内的最近敌人或可破坏石头会把泪以 1.5 rad/s 轻轻带过去；`嗅泪` 仍是全向强追踪（不追石头）。
- 层级：玩家 / 敌人 / Boss / 石头 / 宝箱按脚底 Y 排序；玩家静止时有呼吸 idle；蓄力激光为五层红色等离子 + 枪口/冲击光斑；按住时头顶进度环，充满自动释放，提前松手取消。
- 楼层主题：B1–B15 各自地板/墙/火把/灰烬配色（`view/themes.ts`）；内部墙体布局 `octagon` / `wallPillars` / `alcoves` / `crossWalls`，形成非矩形战斗区
- 数值：普通怪 HP 1.13^(层-1)，Boss 1.16^(层-1)，铁面卫正面减伤 65%；65 件全加约 10.9 伤害 / 4 泪 / 5 射速
- 动效：敌人/Boss 由原图生成 3 帧循环（呼吸/振翅；刺球额外旋转），玩家移动扬尘、枪口闪光、房间灰烬、死亡升魂；商店货架显示真实道具图标。

### 移动

- 加速度 1900 px/s²，松手减速度 1450 px/s²（轻微滑行）
- 斜向输入先归一化，斜向不加速
- 受击硬直 0.2s：期间速度按 `v *= 1 - 4dt` 衰减，击退才推得动人
- 受击无敌 1.25s，闪烁表现
- 碰撞体是半径 8 的圆，视觉 26×34

### 射击

- 四向：上/下/左/右；按住持续射击
- 泪继承 28% 玩家速度（原作手感）
- 泪半径 `6 + min(4, damage × 0.28)` 的缩放版
- 泪寿命 = `range / shotSpeed`
- 命中给敌人击退，命中/撞墙产生飞溅粒子

### 受伤

- 接触伤害与弹幕伤害按半心扣
- 受击：无敌 1.25s + 硬直 0.2s + 击退 + 震屏 + 红闪
- 死亡：原地倒地演出，显示六项统计、道具列表与「再来一次 / 返回主界面」

## 5. 地牢生成

复刻原作算法（Boris the Brave 逆向分析）：

- 9×8 网格，起点 (4, 3)
- 目标房间数：`clamp(4 + round(level × 0.78) + rand(0,1), 5, 13)`
  - 第 1 层 5–6 间，第 12 层 13 间
- 从起点 BFS 扩散，每方向 50% 放弃
- 候选格若已有 **>1 个已填充邻居** 则拒绝 —— 这是「只有走廊、没有环路」的来源
- 队列空了可以把起点重新入队（原作行为），最多重试 6 次；整层最多尝试 400 次
- 死胡同按离起点距离排序：
  - **Boss 房** = 最远死胡同，且距离 ≥ 2（不能挨着起点）
  - **宝物房** = 第二远死胡同
  - **商店** = 第三远死胡同，仅第 2 层起且房间数 ≥ 7
- 不满足条件整层重新生成
- 相邻房间在共享墙正中开门
- 门四种外观：普通 / 宝物（金 + 星）/ 商店（$）/ Boss（红 + 骷髅）
- 小地图显示已探索、当前位置、Boss、宝物、商店、未清房；外框为金边面板，格子范围按本层实际占用裁剪，房间之间画门连线

**实现状态（已跑通）**：BFS 扩张、>1 已填邻居拒绝、队列空重入起点（最多 6 次）、整层 400 次迭代上限都已实现。另外要求最终房间数 ≥ `target - 1`，否则整层重生成（最多 240 次），避免第 12 层只剩 5 间。死胡同按距离降序分配：Boss = 最远（距离 ≥ 2）、宝物 = 第二远、商店 = 第三远（仅第 2 层起且房间数 ≥ 7）；商店只从死胡同里取，不会顶掉普通房。

### 房间布局

13 种模板：空房、四角、立柱、菱形、坑洞群、断行、尖刺环、镜像散布、尖刺走廊、双坑、竞技场、对角碎石、十字立柱。

约束：
- 保留门前通道
- 保留房间正中格
- 保证四方向永远可达

**实现状态（已跑通）**：模板按权重随机（空房权重最高），普通房使用、特殊房（Boss/宝物/商店/起点）恒为空房。生成时先强制清空房间正中（4×3 格）与每个门前的 3 格深通道，再落模板；落完做一次 BFS 可达性检查，若某扇门被堵就随机移除挡路物直到四向可达。

障碍分三种：
- 石头：挡人挡泪，地面敌人也绕不过
- 坑洞：挡人与地面敌人，不挡泪；飞行敌人直接越过
- 尖刺：不挡路，玩家踩上去扣 1 半心（受击无敌 1.25s 生效，不会连续掉血）

## 6. 房间生命周期

1. 进房：敌人出场动画（0.7s / Boss 0.9s），门锁
2. 清怪：门打开（门板缩进 + 暖光），掉落判定
3. 走到门口：切到相邻房间，滑动过渡
4. 房间状态持久化：`cleared`、道具是否已拿、障碍是否被破坏
5. Boss 房清空：掉落奖励道具 + 活板门
6. 踩活板门：下一层，层数 +1
7. 第 15 层 Boss 击败：`ESCAPED` 通关结算

**实现状态**：1 已实现——普通房 0.7s 出场动画（白圈扩散 + 缩放，期间不行动、不受伤），Boss 房白圈放大 + 0.9s 无敌；2 开门 + 掉落判定（金币 / 红心 / 半心 / 道具）；3 截屏旧画面 + 相机滑动过渡，HUD 反向补偿保持固定；4 已持久化 `cleared` / 活板门 / 道具已拿 / 宝箱已开 / 商店 `SOLD` / 石头已碎；5 出活板门 + 必得道具 + 金币与半心；6 已跑通（层数 +1、血量与击杀数保留）；7 第 15 层 Boss 击败后进入 `ESCAPED` 结算。

## 7. 道具（65 件，可叠加）

一局内不重复（道具池洗牌）。掉落途径：宝物房基座（必得）、宝箱、Boss 奖励（必得）、商店、敌人小概率。

| 类别 | 数量 | 机制 |
|---|---|---|
| 改变攻击方式 | 27 | 蓄力激光、穿透、多重射击、追踪、回旋、爆炸泪、反弹、中毒、减速、幽灵泪、分裂、暴击牙、距离增伤、起手增伤、伤害光环、射速暴涨、潮气、蜃泪、苦胆 |
| 改变生存方式 | 8 | 每房首次免伤护盾、全伤害 -1、死亡复活、跟随炮台、自动吸取拾取物、受击反刺、清房回血、击杀回血 |
| 改变属性数值 | 22 | 伤害 / 射速 / 移速 / 弹速 / 射程 / 生命上限 / 幸运 |
| 改变外观 | 8 | 体型、翅膀/飞行、浮空、光环、暗紫光环、脚下印记、环绕物、护盾泡 |

原则：
- 道具在上一件的结果上加或乘，允许叠加
- 外观类道具只改表现，不改碰撞半径
- 协同钩子预留：`onFire`、`onHit`、`onKill`、`onRoomClear`、`onDamage`

**实现状态（已跑通）**：65 件全部实装，按 27 攻击 / 8 生存 / 22 属性 / 8 外观 分布。`Stats` 扩展出泪形态（`tears` / `spread` / `tearSize`）、泪行为（`pierce` / `bounces` / `homing` / `splits` / `poison` / `slow` / `ghost` / `crit` / `blast` / `boomerang` / `farBonus` / `firstBonus` / `beam`）与生存项（`aura` / `turrets` / `shields` / `armor` / `revives` / `magnet` / `retaliate`）。行为都在 `TearManager` 内执行：穿透用 `Set` 去重、反弹按阻挡方向反射、追踪逐帧转向、分裂在消散时生成 55% 伤害小泪、爆炸走场景回调 `blastAt`；蓄力激光由 `Player` 蓄力（0.9s 满），松手后 `GameScene.fireBeam` 做射线判定。生存类接在 `Player.takeDamage`（每房护盾、伤害 -1、半血复活）与 `GameScene`（光环 0.45s 一跳、环绕炮台 0.9s 一发）。外观类只改表现层（体型 / 骨翼 / 浮空 / 光环 / 暗环 / 足印 / 环绕 / 泡膜），不动碰撞半径。掉落：宝物房基座必得、Boss 必得、杂兵 3.5% + 幸运加成；落地 16px 内拾取，`磁心` 80px 内自动吸。中毒只对杂兵生效，对 Boss 折算成即时伤害。新增的「灰烬之肺」走 `onKill`，击杀 25% 概率回半心。

槽位规则：`tears` 是额外泪数，`spread` 是整扇面的总角度（3 泪 + 24° = -12°/0°/+12°）；`splits` 每颗命中的泪都分裂，所以和穿透会叠出大量小泪，这是有意的复利。

## 8. 难度曲线

玩家输出是复利增长：从第 1 层到第 12 层 DPS 约 ×20。

| 对象 | 血量缩放 |
|---|---|
| Boss | `×1.28^(层数-1)` |
| 杂兵 | `×1.24^(层数-1)` |

这两个指数是用机器人实测 DPS 曲线拟合的，不是拍脑袋。线性缩放会让第 12 层 Boss 只撑 5.9 秒。

## 9. 经济与掉落

- 金币：清房、打碎石头、Boss 掉落
- 商店：三个货架，价格随深度上涨；卖道具，偶尔卖红心（生命上限 +1 并回满）
- 红心 / 半心：清房概率、Boss 奖励
- 宝箱：木箱 / 金箱，金箱更好
